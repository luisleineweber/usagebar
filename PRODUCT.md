# Product

## Register

product

## Users

Developers on Windows who use several AI coding subscriptions and need to understand quota, spend, resets, account state, and provider incidents without opening multiple dashboards. They usually check UsageBar briefly from the tray while working in an editor or terminal.

## Product Purpose

UsageBar gives one local, trustworthy view of AI coding usage across providers. Success means a user can answer what is available, what changed, what will reset, what it costs, and whether a provider is healthy from the tray, settings, local API, or terminal, while credentials and raw provider payloads remain on the machine.

## Brand Personality

Focused, transparent, dependable. The product should feel quiet and native to a Windows work session, with enough density for expert users and plain language for setup, errors, and provenance.

## Anti-references

Avoid decorative SaaS dashboards, oversized marketing metrics, glassmorphism, gratuitous animation, provider-specific interface forks, ambiguous credential handling, and novelty controls that replace familiar desktop affordances. Do not copy competitor breadth without a stable Windows auth source and verified entitlement data.

## Design Principles

1. One glance first: put current quota, reset, cost, and incident state before configuration detail.
2. Shared truth: history, charts, notifications, CLI output, and the local API consume the same normalized cached data.
3. Explicit trust boundaries: browser access and credential import are opt-in, narrowly scoped, and absent from diagnostics and API responses.
4. Progressive depth: the tray stays compact while provider detail, history, settings, and terminal output reveal more control.
5. Provider quality over count: new integrations require a real Windows source, fixture coverage, and a verified entitlement or usage check.

## Accessibility & Inclusion

Target WCAG 2.2 AA for text, controls, focus treatment, keyboard operation, and semantic state. Never rely on color alone, preserve usable contrast in light and dark themes, respect reduced-motion preferences, and keep time, cost, and quota values understandable with screen-reader labels.
