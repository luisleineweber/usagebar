P0 — Cost History Charts

Highest-value feature gap. CodexBar has 4 interactive chart types in the menu. UsageBar shows text lines. This is the single biggest UX differentiator we can add.

Cost Summary KPIs + 30-day Bar Chart

Source: CodexBar · CostHistoryChartMenuView.swift
Show Today / 7d / 30d spend KPIs plus interactive 30-day bar chart with daily spend, token, and request counts. Hover for per-day model breakdown.
First steps:
  1. Add ProviderCostSummary type to src/lib/plugin-types.ts
  2. Update plugin runtime to accept optional cost payload in Rust host
  3. Convert Codex/Claude ccusage daily results into structured costSummary
  4. Build CostSummaryCard React component (KPIs + compact 30-day bars)
  5. Add detail page cost tab with daily table, model breakdown, copy/export
✓ Interactive cost history with KPIs and 30-day bars for Codex and Claude
~3 daysP0No new deps

  2. Fetch /v1/organization/costs with 1-day buckets grouped by line_item
  3. Fetch /v1/organization/usage/completions with model grouping
