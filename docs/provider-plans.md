# Provider plan catalog

Research snapshot: 2026-07-27.

The `defaultPlan` value is a display fallback, not a claim about the signed-in account. A plugin's provider-reported `plan` always wins. This distinction matters for API, local-history, BYOK, trial, and unauthenticated providers where UsageBar cannot prove an account subscription.
